A simulation of the path of the Voyager 1 spacecraft, showing its trajectory through the solar system and its gravity assist interactions with Jupiter and Saturn.
The purpose of this project is to demonstrate a physical simulation with ephemeris data from NASA-JPL Horizons System web app.
